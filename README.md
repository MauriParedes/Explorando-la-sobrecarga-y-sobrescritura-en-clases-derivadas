## 📘 Descripción general del sistema
Este proyecto corresponde a la actividad sumativa grupal de la Semana 3 de la asignatura Desarrollo Orientado a Objetos II. Consiste en la implementación del sistema integral de repartos para la empresa SpeedFast, aplicando los principios de herencia, abstracción, polimorfismo e interfaces
---

## 🧱 Estructura general del proyecto

```plaintext
📁 src/
├── interfaces/   # Contiene Despachable, Cancelable y Rastreable
├── modelos/      # Clase abstracta Pedido y subclases PedidoComida, PedidoEncomienda y PedidoExpress
├── servicios/    # Clase ControladorDeEnvios que gestiona el historial mediante ArrayList
└── Main.java     # Clase principal que ejecuta la simulación por consola
````

---

## ⚙️ Instrucciones para clonar y ejecutar el proyecto

1. Clona el repositorio desde GitHub:

```bash
git clone https://github.com/MauriParedes/Explorando-la-sobrecarga-y-sobrescritura-en-clases-derivadas.git
```

2. Abre el proyecto en IntelliJ IDEA.

3. Verifica que la solución esté dentro de la carpeta ` SpeedFast`

4. Ejecuta el archivo `Main.java` 

5. Sigue la salida en consola para verificar la asignación de repartidores, cálculo de tiempo, despacho, cancelación e historial de entregas
